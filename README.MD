Features:

- Set workspace
- Show project tree
- Read file
- Search text across the workspace
- Create file
- Replace text in a file
- Replace an entire function using Tree-sitter
- Use any LLM to edit code through this MCP toll instead of manually copying and pasting code


To Run:
- clone the repository
- create a virtual environment
- install the requirements
- run the server using python server.py
- create an ngrok tunnel for port 8000
- copy the ngrok url
- add the url to the custom mcp section of your llm

- There's SKILL.md file
